Architectural Evaluation Audit

Welcome to the audit

In this form, you will audit technical reviews applied to software diagrams. The goal is to validate the quality of architectural design analyses in microservices projects.

Evaluation flow

For each case presented, the screen will be divided into two panels:

  • On the left: the diagram and its textual description
  • On the right: the evaluation criterion and its guidelines (2 to 4)

Each guideline contains a question about the criterion and a corresponding analysis — this analysis is the material you must audit.

Your task

Evaluate whether the provided technical analysis is accurate and well-founded, using the specific guidelines.

Instructions

  • Judge based on the provided material, both the diagram and the description
  • Use the agreement scale (1-4)
  • Identify issues: hallucinations, omissions, or logical errors
